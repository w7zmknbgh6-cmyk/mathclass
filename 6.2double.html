6.2 二倍角公式

公式推导 · 典型例题 · 练习讲评 · 课堂小结

一、二倍角公式的推导（点击“下一步”逐步出现）
核心思想：在两角和公式中令 $\beta = \alpha$，即可得到二倍角公式。

1. 正弦二倍角公式

从两角和的正弦公式出发：
$$\sin(\alpha + \beta) = \sin\alpha\cos\beta + \cos\alpha\sin\beta$$
令 $\beta = \alpha$，则：
$$\sin(\alpha + \alpha) = \sin\alpha\cos\alpha + \cos\alpha\sin\alpha$$
合并同类项，得到：
$$\sin 2\alpha = 2\sin\alpha\cos\alpha$$

2. 余弦二倍角公式

从两角和的余弦公式出发：
$$\cos(\alpha + \beta) = \cos\alpha\cos\beta - \sin\alpha\sin\beta$$
令 $\beta = \alpha$，则：
$$\cos(\alpha + \alpha) = \cos\alpha\cos\alpha - \sin\alpha\sin\alpha$$
化简得第一种形式：
$$\cos 2\alpha = \cos^2\alpha - \sin^2\alpha$$
利用 $\sin^2\alpha + \cos^2\alpha = 1$ 进行代换：
$$\cos 2\alpha = 2\cos^2\alpha - 1 = 1 - 2\sin^2\alpha$$
因此余弦二倍角公式有三种常用形式：
$$\cos 2\alpha = \cos^2\alpha - \sin^2\alpha = 2\cos^2\alpha - 1 = 1 - 2\sin^2\alpha$$

3. 正切二倍角公式

从两角和的正切公式出发：
$$\tan(\alpha + \beta) = \frac{\tan\alpha + \tan\beta}{1 - \tan\alpha\tan\beta}$$
令 $\beta = \alpha$，则：
$$\tan(\alpha + \alpha) = \frac{\tan\alpha + \tan\alpha}{1 - \tan\alpha\tan\alpha}$$
化简得：
$$\tan 2\alpha = \frac{2\tan\alpha}{1 - \tan^2\alpha}$$

注意：此式成立的前提是 $\tan\alpha$ 有意义，即 $\alpha \neq \frac{\pi}{2} + k\pi$。

二倍角公式总结

$$\sin 2\alpha = 2\sin\alpha\cos\alpha$$

$$\cos 2\alpha = \cos^2\alpha - \sin^2\alpha = 2\cos^2\alpha - 1 = 1 - 2\sin^2\alpha$$

$$\tan 2\alpha = \frac{2\tan\alpha}{1 - \tan^2\alpha}$$

4. 半角公式（探究与发现）

由 $\cos 2\alpha = 1 - 2\sin^2\alpha$，可得：
$$\sin^2\alpha = \frac{1 - \cos 2\alpha}{2}$$
将 $\alpha$ 替换为 $\frac{\alpha}{2}$：
$$\sin^2\frac{\alpha}{2} = \frac{1 - \cos\alpha}{2}$$
同理，由 $\cos 2\alpha = 2\cos^2\alpha - 1$，可得：
$$\cos^2\frac{\alpha}{2} = \frac{1 + \cos\alpha}{2}$$
因此得到半角公式：
$$\sin\frac{\alpha}{2} = \pm\sqrt{\frac{1 - \cos\alpha}{2}}$$
$$\cos\frac{\alpha}{2} = \pm\sqrt{\frac{1 + \cos\alpha}{2}}$$

“$\pm$”由 $\frac{\alpha}{2}$ 所在象限决定。

二、典型例题（答案点击按钮显示）
例 1

已知 $\sin\alpha = \dfrac{4}{5}$，$\alpha$ 是第二象限角，求 $\sin 2\alpha$、$\cos 2\alpha$ 和 $\tan 2\alpha$ 的值。

思路：先由同角关系求 $\cos\alpha$（注意象限定符号），再套用二倍角公式；求 $\tan 2\alpha$ 可先求 $\tan\alpha$ 再用正切二倍角公式。
解答：

因为 $\alpha$ 是第二象限角，所以 $\cos\alpha < 0$。

$$\cos\alpha = -\sqrt{1 - \sin^2\alpha} = -\sqrt{1 - \left(\frac{4}{5}\right)^2} = -\frac{3}{5}$$

$$\sin 2\alpha = 2\sin\alpha\cos\alpha = 2 \times \frac{4}{5} \times \left(-\frac{3}{5}\right) = -\frac{24}{25}$$

$$\cos 2\alpha = 1 - 2\sin^2\alpha = 1 - 2 \times \left(\frac{4}{5}\right)^2 = -\frac{7}{25}$$

$$\tan\alpha = \frac{\sin\alpha}{\cos\alpha} = -\frac{4}{3}$$

$$\tan 2\alpha = \frac{2\tan\alpha}{1 - \tan^2\alpha} = \frac{2 \times (-\frac{4}{3})}{1 - (-\frac{4}{3})^2} = \frac{24}{7}$$

答案：$\sin 2\alpha = -\dfrac{24}{25}$，$\cos 2\alpha = -\dfrac{7}{25}$，$\tan 2\alpha = \dfrac{24}{7}$。

例 2

已知 $\cos\dfrac{\theta}{2} = -\dfrac{1}{3}$，且 $\theta \in (\pi, 2\pi)$，求 $\sin\theta$ 和 $\cos\theta$ 的值。

思路：由 $\theta$ 的范围确定 $\dfrac{\theta}{2}$ 的象限，从而确定 $\sin\dfrac{\theta}{2}$ 的符号；再利用二倍角公式把 $\theta$ 看成 $2 \times \dfrac{\theta}{2}$ 求解。
解答：

由 $\theta \in (\pi, 2\pi)$，可知 $\dfrac{\theta}{2} \in \left(\dfrac{\pi}{2}, \pi\right)$，故 $\sin\dfrac{\theta}{2} > 0$。

$$\sin\frac{\theta}{2} = \sqrt{1 - \cos^2\frac{\theta}{2}} = \sqrt{1 - \left(-\frac{1}{3}\right)^2} = \frac{2\sqrt{2}}{3}$$

$$\sin\theta = 2\sin\frac{\theta}{2}\cos\frac{\theta}{2} = 2 \times \frac{2\sqrt{2}}{3} \times \left(-\frac{1}{3}\right) = -\frac{4\sqrt{2}}{9}$$

$$\cos\theta = 2\cos^2\frac{\theta}{2} - 1 = 2 \times \left(-\frac{1}{3}\right)^2 - 1 = -\frac{7}{9}$$

答案：$\sin\theta = -\dfrac{4\sqrt{2}}{9}$，$\cos\theta = -\dfrac{7}{9}$。

例 3

化简：$\dfrac{\sin 2\alpha + \sin\alpha}{2\cos 2\alpha + 2\sin^2\alpha + \cos\alpha}$。

思路：分子分母分别用二倍角公式展开，再提取公因式约分；注意 $\cos 2\alpha$ 选择消去 $\sin^2\alpha$ 的形式更方便。
解答：

$$\text{原式} = \frac{2\sin\alpha\cos\alpha + \sin\alpha}{2(\cos^2\alpha - \sin^2\alpha) + 2\sin^2\alpha + \cos\alpha}$$

$$= \frac{\sin\alpha(2\cos\alpha + 1)}{2\cos^2\alpha - 2\sin^2\alpha + 2\sin^2\alpha + \cos\alpha}$$

$$= \frac{\sin\alpha(2\cos\alpha + 1)}{2\cos^2\alpha + \cos\alpha}$$

$$= \frac{\sin\alpha(2\cos\alpha + 1)}{\cos\alpha(2\cos\alpha + 1)} = \frac{\sin\alpha}{\cos\alpha} = \tan\alpha$$

答案：$\tan\alpha$。

例 4

证明：$\tan\theta = \dfrac{1 - \cos 2\theta}{\sin 2\theta}$。

思路：从右边出发，把 $\cos 2\theta$ 化为 $1 - 2\sin^2\theta$ 消去常数，再约分。
证明：

$$\text{右边} = \frac{1 - \cos 2\theta}{\sin 2\theta} = \frac{1 - (1 - 2\sin^2\theta)}{2\sin\theta\cos\theta}$$

$$= \frac{2\sin^2\theta}{2\sin\theta\cos\theta} = \frac{\sin\theta}{\cos\theta} = \tan\theta = \text{左边}$$

所以原等式成立。

证毕。

三、练习 6.2（答案与思路点击按钮显示）
练习 6.2 第 1 题

求下列各式的值：

(1) $2\sin 15^\circ\cos 15^\circ$；　(2) $2\cos^2\dfrac{\pi}{12} - 1$；

(3) $1 - 2\sin^2\dfrac{5\pi}{12}$；　(4) $\dfrac{2\tan\dfrac{\pi}{8}}{1 - \tan^2\dfrac{\pi}{8}}$。

思路：四个小题分别对应正弦、余弦、正切的二倍角公式的“逆向”使用，关键是把式子看成 $2\alpha$ 的形式。
解答：

(1) $2\sin 15^\circ\cos 15^\circ = \sin 30^\circ = \dfrac{1}{2}$

(2) $2\cos^2\dfrac{\pi}{12} - 1 = \cos\dfrac{\pi}{6} = \dfrac{\sqrt{3}}{2}$

(3) $1 - 2\sin^2\dfrac{5\pi}{12} = \cos\dfrac{5\pi}{6} = -\dfrac{\sqrt{3}}{2}$

(4) $\dfrac{2\tan\dfrac{\pi}{8}}{1 - \tan^2\dfrac{\pi}{8}} = \tan\dfrac{\pi}{4} = 1$

答案：(1) $\dfrac{1}{2}$；(2) $\dfrac{\sqrt{3}}{2}$；(3) $-\dfrac{\sqrt{3}}{2}$；(4) $1$。

练习 6.2 第 2 题

已知 $\cos\alpha = \dfrac{4}{5}$，$\alpha$ 是第四象限角，求 $\sin 2\alpha$、$\cos 2\alpha$ 和 $\tan 2\alpha$ 的值。

思路：第四象限中 $\sin\alpha < 0$，先求 $\sin\alpha$，再用二倍角公式；求 $\tan 2\alpha$ 可先求 $\tan\alpha$。
解答：

因为 $\alpha$ 是第四象限角，所以 $\sin\alpha = -\sqrt{1 - \cos^2\alpha} = -\sqrt{1 - \dfrac{16}{25}} = -\dfrac{3}{5}$。

$$\sin 2\alpha = 2\sin\alpha\cos\alpha = 2 \times \left(-\frac{3}{5}\right) \times \frac{4}{5} = -\frac{24}{25}$$

$$\cos 2\alpha = 2\cos^2\alpha - 1 = 2 \times \frac{16}{25} - 1 = \frac{7}{25}$$

$$\tan\alpha = \frac{\sin\alpha}{\cos\alpha} = -\frac{3}{4}$$

$$\tan 2\alpha = \frac{2\tan\alpha}{1 - \tan^2\alpha} = \frac{2 \times (-\frac{3}{4})}{1 - \frac{9}{16}} = -\frac{24}{7}$$

答案：$\sin 2\alpha = -\dfrac{24}{25}$，$\cos 2\alpha = \dfrac{7}{25}$，$\tan 2\alpha = -\dfrac{24}{7}$。

练习 6.2 第 3 题

已知 $\sin\dfrac{\theta}{2} = \dfrac{4}{5}$，$\theta \in (0, \pi)$，求 $\sin\theta$ 和 $\cos\theta$ 的值。

思路：由 $\theta$ 的范围可知 $\dfrac{\theta}{2}$ 在第一象限，故 $\cos\dfrac{\theta}{2} > 0$；把 $\theta$ 看成 $2 \times \dfrac{\theta}{2}$ 使用二倍角公式。
解答：

由 $\theta \in (0, \pi)$，可知 $\dfrac{\theta}{2} \in \left(0, \dfrac{\pi}{2}\right)$，故 $\cos\dfrac{\theta}{2} > 0$。

$$\cos\frac{\theta}{2} = \sqrt{1 - \sin^2\frac{\theta}{2}} = \sqrt{1 - \frac{16}{25}} = \frac{3}{5}$$

$$\sin\theta = 2\sin\frac{\theta}{2}\cos\frac{\theta}{2} = 2 \times \frac{4}{5} \times \frac{3}{5} = \frac{24}{25}$$

$$\cos\theta = 1 - 2\sin^2\frac{\theta}{2} = 1 - 2 \times \frac{16}{25} = -\frac{7}{25}$$

答案：$\sin\theta = \dfrac{24}{25}$，$\cos\theta = -\dfrac{7}{25}$。

练习 6.2 第 4 题

化简：

(1) $\sin\dfrac{\theta}{2}\cos\dfrac{\theta}{2}$；　(2) $\cos^4\alpha - \sin^4\alpha$；

(3) $(\cos\alpha - \sin\alpha)^2$；　(4) $\dfrac{1}{1 - \tan\alpha} - \dfrac{1}{1 + \tan\alpha}$。

思路：(1) 逆用 $\sin 2\alpha = 2\sin\alpha\cos\alpha$；(2) 用平方差公式后再用 $\cos 2\alpha$；(3) 展开后用 $\sin 2\alpha$；(4) 通分后逆用正切二倍角公式。
解答：

(1) $\sin\dfrac{\theta}{2}\cos\dfrac{\theta}{2} = \dfrac{1}{2}\sin\theta$

(2) $\cos^4\alpha - \sin^4\alpha = (\cos^2\alpha - \sin^2\alpha)(\cos^2\alpha + \sin^2\alpha) = \cos 2\alpha$

(3) $(\cos\alpha - \sin\alpha)^2 = \cos^2\alpha - 2\sin\alpha\cos\alpha + \sin^2\alpha = 1 - \sin 2\alpha$

(4) $\dfrac{1}{1 - \tan\alpha} - \dfrac{1}{1 + \tan\alpha} = \dfrac{(1 + \tan\alpha) - (1 - \tan\alpha)}{(1 - \tan\alpha)(1 + \tan\alpha)} = \dfrac{2\tan\alpha}{1 - \tan^2\alpha} = \tan 2\alpha$

答案：(1) $\dfrac{1}{2}\sin\theta$；(2) $\cos 2\alpha$；(3) $1 - \sin 2\alpha$；(4) $\tan 2\alpha$。

三、习题 6.2 · A 组 知识巩固
A 组 第 1 题

求下列各式的值：

(1) $\sin 75^\circ\cos 75^\circ$；　(2) $\cos^2 15^\circ - \sin^2 15^\circ$。

思路：(1) 先乘以 2 再除以 2，凑成 $\sin 2\alpha$；(2) 直接逆用 $\cos 2\alpha = \cos^2\alpha - \sin^2\alpha$。
解答：

(1) $\sin 75^\circ\cos 75^\circ = \dfrac{1}{2} \times 2\sin 75^\circ\cos 75^\circ = \dfrac{1}{2}\sin 150^\circ = \dfrac{1}{2} \times \dfrac{1}{2} = \dfrac{1}{4}$

(2) $\cos^2 15^\circ - \sin^2 15^\circ = \cos 30^\circ = \dfrac{\sqrt{3}}{2}$

答案：(1) $\dfrac{1}{4}$；(2) $\dfrac{\sqrt{3}}{2}$。

A 组 第 2 题

已知 $\sin\alpha = -\dfrac{12}{13}$，$\alpha$ 是第三象限角，求 $\sin 2\alpha$、$\cos 2\alpha$ 和 $\tan 2\alpha$ 的值。

思路：第三象限中 $\cos\alpha < 0$，先求 $\cos\alpha$，再套用二倍角公式。
解答：

因为 $\alpha$ 是第三象限角，所以 $\cos\alpha = -\sqrt{1 - \sin^2\alpha} = -\sqrt{1 - \dfrac{144}{169}} = -\dfrac{5}{13}$。

$$\sin 2\alpha = 2\sin\alpha\cos\alpha = 2 \times \left(-\frac{12}{13}\right) \times \left(-\frac{5}{13}\right) = \frac{120}{169}$$

$$\cos 2\alpha = 1 - 2\sin^2\alpha = 1 - 2 \times \frac{144}{169} = -\frac{119}{169}$$

$$\tan\alpha = \frac{\sin\alpha}{\cos\alpha} = \frac{12}{5}$$

$$\tan 2\alpha = \frac{2\tan\alpha}{1 - \tan^2\alpha} = \frac{\frac{24}{5}}{1 - \frac{144}{25}} = -\frac{120}{119}$$

答案：$\sin 2\alpha = \dfrac{120}{169}$，$\cos 2\alpha = -\dfrac{119}{169}$，$\tan 2\alpha = -\dfrac{120}{119}$。

A 组 第 3 题

化简：

(1) $2\sin(\pi + \alpha)\cos(\pi - \alpha)$；　(2) $\dfrac{1 + \sin 2\theta}{\sin\theta + \cos\theta}$；

(3) $1 + 2\cos^2\theta - \cos 2\theta$；　(4) $1 + \cos\alpha + 2\sin^2\dfrac{\alpha}{2}$。

思路：综合利用诱导公式、二倍角公式及 $1 = \sin^2\theta + \cos^2\theta$ 进行变形化简。
解答：

(1) $2\sin(\pi + \alpha)\cos(\pi - \alpha) = 2(-\sin\alpha)(-\cos\alpha) = 2\sin\alpha\cos\alpha = \sin 2\alpha$

(2) $\dfrac{1 + \sin 2\theta}{\sin\theta + \cos\theta} = \dfrac{\sin^2\theta + \cos^2\theta + 2\sin\theta\cos\theta}{\sin\theta + \cos\theta} = \dfrac{(\sin\theta + \cos\theta)^2}{\sin\theta + \cos\theta} = \sin\theta + \cos\theta$

(3) $1 + 2\cos^2\theta - \cos 2\theta = 1 + 2\cos^2\theta - (2\cos^2\theta - 1) = 2$

(4) $1 + \cos\alpha + 2\sin^2\dfrac{\alpha}{2} = 1 + \cos\alpha + 2 \times \dfrac{1 - \cos\alpha}{2} = 1 + \cos\alpha + 1 - \cos\alpha = 2$

答案：(1) $\sin 2\alpha$；(2) $\sin\theta + \cos\theta$；(3) $2$；(4) $2$。

三、习题 6.2 · B 组 能力提升
B 组 第 1 题

已知 $\cos\dfrac{\alpha}{2} = -\dfrac{3}{5}$，$\alpha \in \left(\pi, \dfrac{3\pi}{2}\right)$，求 $\sin\left(\alpha + \dfrac{\pi}{3}\right)$ 的值。

思路：先由 $\alpha$ 的范围确定 $\dfrac{\alpha}{2}$ 在第二象限，求出 $\sin\dfrac{\alpha}{2}$；再用二倍角公式求 $\sin\alpha$、$\cos\alpha$；最后用和角公式展开。
解答：

由 $\alpha \in \left(\pi, \dfrac{3\pi}{2}\right)$，可知 $\dfrac{\alpha}{2} \in \left(\dfrac{\pi}{2}, \dfrac{3\pi}{4}\right)$，故 $\sin\dfrac{\alpha}{2} > 0$。

$$\sin\frac{\alpha}{2} = \sqrt{1 - \frac{9}{25}} = \frac{4}{5}$$

$$\sin\alpha = 2 \times \frac{4}{5} \times \left(-\frac{3}{5}\right) = -\frac{24}{25}$$

$$\cos\alpha = 2\cos^2\frac{\alpha}{2} - 1 = 2 \times \frac{9}{25} - 1 = -\frac{7}{25}$$

$$\sin\left(\alpha + \frac{\pi}{3}\right) = \sin\alpha\cos\frac{\pi}{3} + \cos\alpha\sin\frac{\pi}{3}$$

$$= \left(-\frac{24}{25}\right) \times \frac{1}{2} + \left(-\frac{7}{25}\right) \times \frac{\sqrt{3}}{2} = -\frac{24 + 7\sqrt{3}}{50}$$

答案：$-\dfrac{24 + 7\sqrt{3}}{50}$。

B 组 第 2 题

证明：

(1) $\sin\theta(1 + \cos 2\theta) = \sin 2\theta\cos\theta$；

(2) $\dfrac{1 - \cos 2\theta + \sin 2\theta}{1 + \cos 2\theta + \sin 2\theta} = \tan\theta$。

思路：(1) 把 $\cos 2\theta$ 换成 $2\cos^2\theta$；(2) 分子分母分别用 $1 - \cos 2\theta = 2\sin^2\theta$、$1 + \cos 2\theta = 2\cos^2\theta$ 化简，再约分。
证明：

(1) 左边 $= \sin\theta \times 2\cos^2\theta = 2\sin\theta\cos^2\theta$

右边 $= 2\sin\theta\cos\theta \times \cos\theta = 2\sin\theta\cos^2\theta$

左边 $=$ 右边，原等式成立。

(2) 左边 $= \dfrac{2\sin^2\theta + 2\sin\theta\cos\theta}{2\cos^2\theta + 2\sin\theta\cos\theta} = \dfrac{2\sin\theta(\sin\theta + \cos\theta)}{2\cos\theta(\cos\theta + \sin\theta)} = \dfrac{\sin\theta}{\cos\theta} = \tan\theta = $ 右边

原等式成立。

证毕。

B 组 第 3 题

已知点 $P(3, 4)$ 是角 $\alpha$ 终边上的一点，求 $\cos\left(\dfrac{\pi}{3} + 2\alpha\right)$ 的值。

思路：先由点的坐标求 $\sin\alpha$、$\cos\alpha$；再用二倍角公式求 $\sin 2\alpha$、$\cos 2\alpha$；最后用和角公式展开。
解答：

$$r = \sqrt{3^2 + 4^2} = 5$$

$$\sin\alpha = \frac{4}{5},\quad \cos\alpha = \frac{3}{5}$$

$$\sin 2\alpha = 2 \times \frac{4}{5} \times \frac{3}{5} = \frac{24}{25}$$

$$\cos 2\alpha = 2\cos^2\alpha - 1 = 2 \times \frac{9}{25} - 1 = -\frac{7}{25}$$

$$\cos\left(\frac{\pi}{3} + 2\alpha\right) = \cos\frac{\pi}{3}\cos 2\alpha - \sin\frac{\pi}{3}\sin 2\alpha$$

$$= \frac{1}{2} \times \left(-\frac{7}{25}\right) - \frac{\sqrt{3}}{2} \times \frac{24}{25} = -\frac{7 + 24\sqrt{3}}{50}$$

答案：$-\dfrac{7 + 24\sqrt{3}}{50}$。

三、习题 6.2 · C 组 学以致用
C 组 思考题

小明在解决某个数学问题时，误将 $\cos^2\alpha$ 写成了 $\cos 2\alpha$，但最终答案是正确的。请你想一想，$\alpha$ 可能是什么角？

思路：“答案正确”意味着 $\cos^2\alpha = \cos 2\alpha$。把 $\cos 2\alpha$ 用 $2\cos^2\alpha - 1$ 表示，解方程即可。
解答：

由题意，需满足：

$$\cos^2\alpha = \cos 2\alpha$$

代入二倍角公式：

$$\cos^2\alpha = 2\cos^2\alpha - 1$$

$$\cos^2\alpha = 1$$

$$\cos\alpha = \pm 1$$

因此 $\alpha = k\pi$（$k \in \mathbb{Z}$）。

答案：$\alpha = k\pi$，$k \in \mathbb{Z}$。

四、课堂小结与做题技巧

1. 公式结构

  • $\sin 2\alpha = 2\sin\alpha\cos\alpha$
  • $\cos 2\alpha$ 三种形式灵活选用
  • $\tan 2\alpha = \dfrac{2\tan\alpha}{1 - \tan^2\alpha}$

2. 适用条件

  • 正切公式要求 $\tan\alpha$ 有意义
  • 开方时必须先确定角的象限
  • 半角公式中“$\pm$”看 $\dfrac{\alpha}{2}$ 所在象限

3. 常见配凑

  • $\alpha = 2 \times \dfrac{\alpha}{2}$（半角变倍角）
  • $1 = \sin^2\theta + \cos^2\theta$
  • $1 \pm \sin 2\theta = (\sin\theta \pm \cos\theta)^2$

4. 解题技巧

  • 先定象限，再定符号
  • 遇“$1$”常配成平方和
  • 化简时先展开二倍角，再因式分解
  • 证明题从复杂的一边化向简单的一边
