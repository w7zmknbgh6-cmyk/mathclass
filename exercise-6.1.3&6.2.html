6.1 两角和与差的正切公式

核心公式

$$\tan(\alpha + \beta) = \frac{\tan\alpha + \tan\beta}{1 - \tan\alpha\tan\beta}$$

$$\tan(\alpha - \beta) = \frac{\tan\alpha - \tan\beta}{1 + \tan\alpha\tan\beta}$$

常用技巧：$1 = \tan 45^\circ$，整体代换公式结构。

边学边做 2
1

计算：$\dfrac{\tan 34^\circ + \tan 26^\circ}{1 - \tan 34^\circ\tan 26^\circ}$。

答案：$\sqrt{3}$
解析

原式 $= \tan(34^\circ + 26^\circ) = \tan 60^\circ = \sqrt{3}$。

2

计算：$\dfrac{1 - \tan 75^\circ}{1 + \tan 75^\circ}$。

答案：$-\dfrac{\sqrt{3}}{3}$
解析

将 $1$ 写成 $\tan 45^\circ$，则

原式 $= \dfrac{\tan 45^\circ - \tan 75^\circ}{1 + \tan 45^\circ\tan 75^\circ} = \tan(45^\circ - 75^\circ) = \tan(-30^\circ) = -\dfrac{\sqrt{3}}{3}$。

巩固提升 · A 组

（一）选择题

1

计算：$\tan 75^\circ = (\quad)$。

A. $2 - \sqrt{3}$　B. $-2 - \sqrt{3}$　C. $2 + \sqrt{3}$　D. $-2 + \sqrt{3}$

答案：C
解析

$\tan 75^\circ = \tan(45^\circ + 30^\circ) = \dfrac{1 + \frac{\sqrt{3}}{3}}{1 - 1 \times \frac{\sqrt{3}}{3}} = \dfrac{\sqrt{3} + 1}{\sqrt{3} - 1} = \dfrac{(\sqrt{3} + 1)^2}{2} = 2 + \sqrt{3}$。

2

已知 $\tan\alpha = 3$，则 $\tan\left(\alpha - \dfrac{\pi}{4}\right) = (\quad)$。

A. $-2$　B. $-\dfrac{1}{2}$　C. $\dfrac{1}{2}$　D. $1$

答案：C
解析

$\tan\left(\alpha - \dfrac{\pi}{4}\right) = \dfrac{\tan\alpha - \tan\frac{\pi}{4}}{1 + \tan\alpha\tan\frac{\pi}{4}} = \dfrac{3 - 1}{1 + 3} = \dfrac{1}{2}$。

3

已知 $\tan\alpha = \dfrac{1}{3}$，$\tan\beta = \dfrac{1}{4}$，则 $\tan(\alpha - \beta) = (\quad)$。

A. $\dfrac{7}{11}$　B. $\dfrac{1}{13}$　C. $-\dfrac{1}{13}$　D. $-\dfrac{7}{11}$

答案：B
解析

$\tan(\alpha - \beta) = \dfrac{\frac{1}{3} - \frac{1}{4}}{1 + \frac{1}{3} \times \frac{1}{4}} = \dfrac{\frac{1}{12}}{\frac{13}{12}} = \dfrac{1}{13}$。

4

计算：$\dfrac{\tan 18^\circ + \tan 42^\circ}{1 - \tan 42^\circ\tan 18^\circ} = (\quad)$。

A. $\dfrac{\sqrt{3}}{3}$　B. $\dfrac{\sqrt{2}}{2}$　C. $\dfrac{\sqrt{3}}{2}$　D. $\sqrt{3}$

答案：D
解析

原式 $= \tan(18^\circ + 42^\circ) = \tan 60^\circ = \sqrt{3}$。

（二）填空题

1

计算：$\dfrac{\tan 95^\circ - \tan 35^\circ}{1 + \tan 95^\circ\tan 35^\circ} = \_\_\_\_\_\_\_$。

答案：$\sqrt{3}$
解析

原式 $= \tan(95^\circ - 35^\circ) = \tan 60^\circ = \sqrt{3}$。

2

计算：$\tan 105^\circ = \_\_\_\_\_\_\_$。

答案：$-2 - \sqrt{3}$
解析

$\tan 105^\circ = \tan(60^\circ + 45^\circ) = \dfrac{\sqrt{3} + 1}{1 - \sqrt{3}} = \dfrac{(\sqrt{3} + 1)^2}{1 - 3} = -2 - \sqrt{3}$。

（三）解答题

1

求 $\tan 165^\circ$ 的值。

答案：$\sqrt{3} - 2$
解析

$\tan 165^\circ = \tan(180^\circ - 15^\circ) = -\tan 15^\circ = -(2 - \sqrt{3}) = \sqrt{3} - 2$。

2

已知 $\tan\left(\alpha + \dfrac{\pi}{4}\right) = 3$，求 $\tan\alpha$ 的值。

答案：$\dfrac{1}{2}$
解析

由 $\tan\left(\alpha + \dfrac{\pi}{4}\right) = \dfrac{\tan\alpha + 1}{1 - \tan\alpha} = 3$，

得 $\tan\alpha + 1 = 3 - 3\tan\alpha$，即 $4\tan\alpha = 2$，所以 $\tan\alpha = \dfrac{1}{2}$。

3

已知 $\sin\alpha = \dfrac{3}{5}$，$\alpha \in \left(\dfrac{\pi}{2}, \pi\right)$，$\tan\beta = \dfrac{1}{2}$，求 $\tan(\alpha - \beta)$ 的值。

答案：$-2$
解析

因为 $\alpha \in \left(\dfrac{\pi}{2}, \pi\right)$，所以 $\cos\alpha = -\sqrt{1 - \frac{9}{25}} = -\dfrac{4}{5}$，$\tan\alpha = -\dfrac{3}{4}$。

$\tan(\alpha - \beta) = \dfrac{-\frac{3}{4} - \frac{1}{2}}{1 + (-\frac{3}{4}) \times \frac{1}{2}} = \dfrac{-\frac{5}{4}}{\frac{5}{8}} = -2$。

巩固提升 · B 组

（一）选择题

1

已知 $\tan\alpha$，$\tan\beta$ 是方程 $x^2 - (1 + \sqrt{3})x + \sqrt{3} = 0$ 的两个实数根，则 $\tan(\alpha + \beta) = (\quad)$。

A. $-2 - \sqrt{3}$　B. $-2 + \sqrt{3}$　C. $2 - \sqrt{3}$　D. $2 + \sqrt{3}$

答案：A
解析

由韦达定理：$\tan\alpha + \tan\beta = 1 + \sqrt{3}$，$\tan\alpha\tan\beta = \sqrt{3}$。

$\tan(\alpha + \beta) = \dfrac{1 + \sqrt{3}}{1 - \sqrt{3}} = \dfrac{(1 + \sqrt{3})^2}{1 - 3} = -2 - \sqrt{3}$。

2

计算：$\dfrac{1 - \tan 15^\circ}{1 + \tan 15^\circ} = (\quad)$。

A. $\dfrac{\sqrt{3}}{3}$　B. $\dfrac{\sqrt{2}}{2}$　C. $\dfrac{\sqrt{3}}{2}$　D. $\sqrt{3}$

答案：A
解析

原式 $= \dfrac{\tan 45^\circ - \tan 15^\circ}{1 + \tan 45^\circ\tan 15^\circ} = \tan(45^\circ - 15^\circ) = \tan 30^\circ = \dfrac{\sqrt{3}}{3}$。

（二）填空题

1

已知点 $M(3, -4)$ 是角 $\alpha$ 终边上的一点，则 $\tan\left(\alpha + \dfrac{\pi}{4}\right) = \_\_\_\_\_\_\_$。

答案：$-\dfrac{1}{7}$
解析

$\tan\alpha = \dfrac{-4}{3} = -\dfrac{4}{3}$。

$\tan\left(\alpha + \dfrac{\pi}{4}\right) = \dfrac{-\frac{4}{3} + 1}{1 - (-\frac{4}{3}) \times 1} = \dfrac{-\frac{1}{3}}{\frac{7}{3}} = -\dfrac{1}{7}$。

2

已知 $\alpha + \beta = \dfrac{\pi}{4}$，则 $(1 + \tan\alpha)(1 + \tan\beta) = \_\_\_\_\_\_\_$。

答案：$2$
解析

因为 $\alpha + \beta = \dfrac{\pi}{4}$，所以 $\tan(\alpha + \beta) = 1$，即 $\dfrac{\tan\alpha + \tan\beta}{1 - \tan\alpha\tan\beta} = 1$。

故 $\tan\alpha + \tan\beta = 1 - \tan\alpha\tan\beta$。

$(1 + \tan\alpha)(1 + \tan\beta) = 1 + \tan\alpha + \tan\beta + \tan\alpha\tan\beta = 1 + (1 - \tan\alpha\tan\beta) + \tan\alpha\tan\beta = 2$。

（三）解答题

1

已知 $\tan\alpha$，$\tan\beta$ 是方程 $x^2 - 4x - 7 = 0$ 的两个实根，求 $\tan(\alpha + \beta)$ 的值。

答案：$\dfrac{1}{2}$
解析

由韦达定理：$\tan\alpha + \tan\beta = 4$，$\tan\alpha\tan\beta = -7$。

$\tan(\alpha + \beta) = \dfrac{4}{1 - (-7)} = \dfrac{4}{8} = \dfrac{1}{2}$。

6.2 二倍角公式

核心公式

$$\sin 2\alpha = 2\sin\alpha\cos\alpha$$

$$\cos 2\alpha = \cos^2\alpha - \sin^2\alpha = 2\cos^2\alpha - 1 = 1 - 2\sin^2\alpha$$

$$\tan 2\alpha = \frac{2\tan\alpha}{1 - \tan^2\alpha}$$

常用变形：$\sin^2\alpha = \dfrac{1 - \cos 2\alpha}{2}$，$\cos^2\alpha = \dfrac{1 + \cos 2\alpha}{2}$。

边学边做 1
1

已知 $\sin\alpha = \dfrac{1}{5}$，则 $\sin^4\alpha - \cos^4\alpha = (\quad)$。

A. $-\dfrac{24}{25}$　B. $-\dfrac{23}{25}$　C. $\dfrac{23}{25}$　D. $\dfrac{24}{25}$

答案：B
解析

$\sin^4\alpha - \cos^4\alpha = (\sin^2\alpha - \cos^2\alpha)(\sin^2\alpha + \cos^2\alpha) = \sin^2\alpha - \cos^2\alpha = -(\cos^2\alpha - \sin^2\alpha) = -\cos 2\alpha$。

$\cos 2\alpha = 1 - 2\sin^2\alpha = 1 - 2 \times \dfrac{1}{25} = \dfrac{23}{25}$。

所以原式 $= -\dfrac{23}{25}$。

2

已知 $\cos\alpha = \dfrac{1}{4}$，$\alpha \in \left(\dfrac{3\pi}{2}, 2\pi\right)$，求 $\sin\dfrac{\alpha}{2}$、$\cos\dfrac{\alpha}{2}$、$\tan\dfrac{\alpha}{2}$ 的值。

答案：$\sin\dfrac{\alpha}{2} = \dfrac{\sqrt{6}}{4}$，$\cos\dfrac{\alpha}{2} = -\dfrac{\sqrt{10}}{4}$，$\tan\dfrac{\alpha}{2} = -\dfrac{\sqrt{15}}{5}$
解析

由 $\alpha \in \left(\dfrac{3\pi}{2}, 2\pi\right)$，得 $\dfrac{\alpha}{2} \in \left(\dfrac{3\pi}{4}, \pi\right)$，故 $\sin\dfrac{\alpha}{2} > 0$，$\cos\dfrac{\alpha}{2} < 0$。

$\sin\dfrac{\alpha}{2} = \sqrt{\dfrac{1 - \cos\alpha}{2}} = \sqrt{\dfrac{1 - \frac{1}{4}}{2}} = \dfrac{\sqrt{6}}{4}$。

$\cos\dfrac{\alpha}{2} = -\sqrt{\dfrac{1 + \cos\alpha}{2}} = -\sqrt{\dfrac{1 + \frac{1}{4}}{2}} = -\dfrac{\sqrt{10}}{4}$。

$\tan\dfrac{\alpha}{2} = \dfrac{\sin\frac{\alpha}{2}}{\cos\frac{\alpha}{2}} = -\dfrac{\sqrt{15}}{5}$。

典例解析 2
证明题

证明：$\dfrac{2\cos 2\alpha}{\dfrac{\cos\alpha}{\sin\alpha} - \tan\alpha} = \sin 2\alpha$。

证明

$\dfrac{\cos\alpha}{\sin\alpha} - \tan\alpha = \dfrac{\cos\alpha}{\sin\alpha} - \dfrac{\sin\alpha}{\cos\alpha} = \dfrac{\cos^2\alpha - \sin^2\alpha}{\sin\alpha\cos\alpha} = \dfrac{\cos 2\alpha}{\sin\alpha\cos\alpha}$。

左边 $= \dfrac{2\cos 2\alpha}{\frac{\cos 2\alpha}{\sin\alpha\cos\alpha}} = 2\cos 2\alpha \cdot \dfrac{\sin\alpha\cos\alpha}{\cos 2\alpha} = 2\sin\alpha\cos\alpha = \sin 2\alpha = $ 右边。

所以原等式成立。

边学边做 2
证明题

证明：$1 + 2\cos^2\alpha - \cos 2\alpha = 2$。

证明

左边 $= 1 + 2\cos^2\alpha - (2\cos^2\alpha - 1) = 1 + 2\cos^2\alpha - 2\cos^2\alpha + 1 = 2 = $ 右边。

所以原等式成立。

典例解析 3
化简题

已知 $\tan\alpha = 3$，化简：$\sin^2\alpha + \sin 2\alpha - 5\cos^2\alpha$。

答案：$1$
解析

由 $\tan\alpha = 3$，得 $\sin\alpha = 3\cos\alpha$。

原式 $= (3\cos\alpha)^2 + 2 \cdot 3\cos\alpha \cdot \cos\alpha - 5\cos^2\alpha = 9\cos^2\alpha + 6\cos^2\alpha - 5\cos^2\alpha = 10\cos^2\alpha$。

由 $\sin^2\alpha + \cos^2\alpha = 1$，即 $9\cos^2\alpha + \cos^2\alpha = 1$，得 $\cos^2\alpha = \dfrac{1}{10}$。

所以原式 $= 10 \times \dfrac{1}{10} = 1$。

边学边做 3
1

化简：$\dfrac{\sin 2\alpha - \cos 2\alpha + 1}{\cos\alpha + \sin\alpha}$。

答案：$2\sin\alpha$
解析

分子 $= 2\sin\alpha\cos\alpha - (1 - 2\sin^2\alpha) + 1 = 2\sin\alpha\cos\alpha + 2\sin^2\alpha = 2\sin\alpha(\cos\alpha + \sin\alpha)$。

原式 $= \dfrac{2\sin\alpha(\cos\alpha + \sin\alpha)}{\cos\alpha + \sin\alpha} = 2\sin\alpha$。

2

若 $\tan\alpha + \dfrac{1}{\tan\alpha} = 6$，求 $\sin 2\alpha$ 的值。

答案：$\dfrac{1}{3}$
解析

$\tan\alpha + \dfrac{1}{\tan\alpha} = \dfrac{\sin\alpha}{\cos\alpha} + \dfrac{\cos\alpha}{\sin\alpha} = \dfrac{\sin^2\alpha + \cos^2\alpha}{\sin\alpha\cos\alpha} = \dfrac{1}{\sin\alpha\cos\alpha} = 6$。

所以 $\sin\alpha\cos\alpha = \dfrac{1}{6}$，$\sin 2\alpha = 2\sin\alpha\cos\alpha = \dfrac{1}{3}$。

（一）选择题

1

已知 $\sin 2x = a - 1$，则实数 $a$ 的取值范围为 $(\quad)$。

A. $[-1, 1]$　B. $[0, 1]$　C. $[0, 2]$　D. $[-2, 0]$

答案：C
解析

因为 $-1 \le \sin 2x \le 1$，所以 $-1 \le a - 1 \le 1$，解得 $0 \le a \le 2$。

2

已知 $\cos\alpha = -\dfrac{2}{3}$，且 $\alpha \in \left(\pi, \dfrac{3\pi}{2}\right)$，则 $\sin 2\alpha = (\quad)$。

A. $-\dfrac{\sqrt{5}}{3}$　B. $\dfrac{\sqrt{5}}{3}$　C. $-\dfrac{4\sqrt{5}}{9}$　D. $\dfrac{4\sqrt{5}}{9}$

答案：D
解析

因为 $\alpha \in \left(\pi, \dfrac{3\pi}{2}\right)$，所以 $\sin\alpha = -\sqrt{1 - \frac{4}{9}} = -\dfrac{\sqrt{5}}{3}$。

$\sin 2\alpha = 2\sin\alpha\cos\alpha = 2 \times \left(-\dfrac{\sqrt{5}}{3}\right) \times \left(-\dfrac{2}{3}\right) = \dfrac{4\sqrt{5}}{9}$。

3

已知 $\tan\alpha = -\sqrt{2}$，则 $\tan 2\alpha = (\quad)$。

A. $-\dfrac{2\sqrt{2}}{3}$　B. $\dfrac{2\sqrt{2}}{3}$　C. $\sqrt{2}$　D. $2\sqrt{2}$

答案：D
解析

$\tan 2\alpha = \dfrac{2\tan\alpha}{1 - \tan^2\alpha} = \dfrac{2 \times (-\sqrt{2})}{1 - 2} = 2\sqrt{2}$。

4

若 $\sin\alpha = \dfrac{1}{3}$，则 $\cos^4\alpha - \sin^4\alpha = (\quad)$。

A. $1$　B. $\dfrac{7}{9}$　C. $-\dfrac{7}{9}$　D. $-1$

答案：B
解析

$\cos^4\alpha - \sin^4\alpha = (\cos^2\alpha - \sin^2\alpha)(\cos^2\alpha + \sin^2\alpha) = \cos 2\alpha = 1 - 2\sin^2\alpha = 1 - \dfrac{2}{9} = \dfrac{7}{9}$。

（二）填空题

1

计算：(1) $1 - 2\sin^2\dfrac{\pi}{12} = \_\_\_\_\_\_\_$；(2) $\sin 15^\circ\cos 15^\circ = \_\_\_\_\_\_\_$。

答案：(1) $\dfrac{\sqrt{3}}{2}$；(2) $\dfrac{1}{4}$
解析

(1) $1 - 2\sin^2\dfrac{\pi}{12} = \cos\dfrac{\pi}{6} = \dfrac{\sqrt{3}}{2}$。

(2) $\sin 15^\circ\cos 15^\circ = \dfrac{1}{2}\sin 30^\circ = \dfrac{1}{4}$。

2

若角 $\alpha$ 的终边经过点 $P\left(\dfrac{1}{2}, -\dfrac{\sqrt{3}}{2}\right)$，则 $\sin 2\alpha = \_\_\_\_\_\_\_$。

答案：$-\dfrac{\sqrt{3}}{2}$
解析

$r = 1$，所以 $\sin\alpha = -\dfrac{\sqrt{3}}{2}$，$\cos\alpha = \dfrac{1}{2}$。

$\sin 2\alpha = 2\sin\alpha\cos\alpha = 2 \times \left(-\dfrac{\sqrt{3}}{2}\right) \times \dfrac{1}{2} = -\dfrac{\sqrt{3}}{2}$。

（三）解答题

1

已知 $\sin\alpha = -\dfrac{4}{5}$，$\alpha \in \left(\pi, \dfrac{3\pi}{2}\right)$，求 $\sin 2\alpha$、$\cos 2\alpha$、$\tan 2\alpha$ 的值。

答案：$\sin 2\alpha = \dfrac{24}{25}$，$\cos 2\alpha = -\dfrac{7}{25}$，$\tan 2\alpha = -\dfrac{24}{7}$
解析

因为 $\alpha \in \left(\pi, \dfrac{3\pi}{2}\right)$，所以 $\cos\alpha = -\sqrt{1 - \frac{16}{25}} = -\dfrac{3}{5}$。

$\sin 2\alpha = 2\sin\alpha\cos\alpha = 2 \times \left(-\dfrac{4}{5}\right) \times \left(-\dfrac{3}{5}\right) = \dfrac{24}{25}$。

$\cos 2\alpha = 1 - 2\sin^2\alpha = 1 - 2 \times \dfrac{16}{25} = -\dfrac{7}{25}$。

$\tan\alpha = \dfrac{\sin\alpha}{\cos\alpha} = \dfrac{4}{3}$，$\tan 2\alpha = \dfrac{2 \times \frac{4}{3}}{1 - \frac{16}{9}} = -\dfrac{24}{7}$。

2

化简：$\dfrac{\sin 2\alpha - \sin\alpha}{\cos 2\alpha + 1 - \cos\alpha}$。

答案：$\tan\alpha$
解析

分子 $= 2\sin\alpha\cos\alpha - \sin\alpha = \sin\alpha(2\cos\alpha - 1)$。

分母 $= (2\cos^2\alpha - 1) + 1 - \cos\alpha = 2\cos^2\alpha - \cos\alpha = \cos\alpha(2\cos\alpha - 1)$。

原式 $= \dfrac{\sin\alpha(2\cos\alpha - 1)}{\cos\alpha(2\cos\alpha - 1)} = \dfrac{\sin\alpha}{\cos\alpha} = \tan\alpha$。

（一）选择题

1

已知 $\cos\alpha = \dfrac{4}{5}$，$\alpha \in (0, \pi)$，则 $\sin\dfrac{\alpha}{2} = (\quad)$。

A. $\pm\dfrac{\sqrt{10}}{10}$　B. $\pm\dfrac{\sqrt{10}}{5}$　C. $\dfrac{\sqrt{10}}{10}$　D. $\dfrac{\sqrt{10}}{5}$

答案：C
解析

因为 $\alpha \in (0, \pi)$，所以 $\dfrac{\alpha}{2} \in \left(0, \dfrac{\pi}{2}\right)$，$\sin\dfrac{\alpha}{2} > 0$。

$\sin\dfrac{\alpha}{2} = \sqrt{\dfrac{1 - \cos\alpha}{2}} = \sqrt{\dfrac{1 - \frac{4}{5}}{2}} = \dfrac{\sqrt{10}}{10}$。

2

计算：$\dfrac{\tan\dfrac{\pi}{12}}{1 - \tan^2\dfrac{\pi}{12}} = (\quad)$。

A. $\dfrac{\sqrt{3}}{3}$　B. $\dfrac{\sqrt{3}}{2}$　C. $\dfrac{\sqrt{3}}{6}$　D. $\sqrt{3}$

答案：C
解析

原式 $= \dfrac{1}{2} \cdot \dfrac{2\tan\frac{\pi}{12}}{1 - \tan^2\frac{\pi}{12}} = \dfrac{1}{2}\tan\dfrac{\pi}{6} = \dfrac{1}{2} \times \dfrac{\sqrt{3}}{3} = \dfrac{\sqrt{3}}{6}$。

3

若角 $\alpha$ 是 $\triangle ABC$ 的一个最大内角，且 $\sin\alpha - \cos\alpha = \dfrac{2}{3}$，则 $\triangle ABC$ 是 $(\quad)$。

A. 锐角三角形　B. 等边三角形　C. 直角三角形　D. 钝角三角形

答案：A
解析

由 $\sin\alpha - \cos\alpha = \dfrac{2}{3}$，两边平方得 $1 - \sin 2\alpha = \dfrac{4}{9}$，所以 $\sin 2\alpha = \dfrac{5}{9} > 0$。

因为 $\alpha$ 是最大内角，所以 $\alpha \in \left(\dfrac{\pi}{3}, \pi\right)$，$2\alpha \in \left(\dfrac{2\pi}{3}, 2\pi\right)$。

由 $\sin 2\alpha > 0$ 得 $2\alpha \in \left(\dfrac{2\pi}{3}, \pi\right)$，所以 $\alpha \in \left(\dfrac{\pi}{3}, \dfrac{\pi}{2}\right)$。

最大内角为锐角，故 $\triangle ABC$ 是锐角三角形。

4

已知 $\sin 2\alpha = \dfrac{1}{2}$，$\alpha \in (0, \pi)$，则 $\alpha = (\quad)$。

A. $\dfrac{\pi}{12}$ 或 $\dfrac{5\pi}{6}$　B. $\dfrac{\pi}{6}$ 或 $\dfrac{5\pi}{6}$　C. $\dfrac{\pi}{12}$ 或 $\dfrac{5\pi}{12}$　D. $\dfrac{\pi}{6}$ 或 $\dfrac{5\pi}{12}$

答案：C
解析

因为 $\alpha \in (0, \pi)$，所以 $2\alpha \in (0, 2\pi)$。

由 $\sin 2\alpha = \dfrac{1}{2}$，得 $2\alpha = \dfrac{\pi}{6}$ 或 $\dfrac{5\pi}{6}$。

所以 $\alpha = \dfrac{\pi}{12}$ 或 $\dfrac{5\pi}{12}$。

（二）填空题

1

已知函数 $f(x) = \dfrac{1}{1 + \sin 2x}$，则 $f(x)$ 的定义域是 $\_\_\_\_\_\_\_$。

答案：$\left\{x \mid x \neq \dfrac{3\pi}{4} + k\pi, k \in \mathbb{Z}\right\}$
解析

由 $1 + \sin 2x \neq 0$，得 $\sin 2x \neq -1$。

$2x \neq \dfrac{3\pi}{2} + 2k\pi$，即 $x \neq \dfrac{3\pi}{4} + k\pi$（$k \in \mathbb{Z}$）。

2

化简：$2 - 2\sin^2\alpha - \cos 2\alpha = \_\_\_\_\_\_\_$。

答案：$1$
解析

原式 $= 2(1 - \sin^2\alpha) - \cos 2\alpha = 2\cos^2\alpha - (2\cos^2\alpha - 1) = 1$。

（三）解答题

1

证明：$\dfrac{1 + \sin 2\alpha + \cos 2\alpha}{\cos\alpha + \sin\alpha} = 2\cos\alpha$。

证明

分子 $= \sin^2\alpha + \cos^2\alpha + 2\sin\alpha\cos\alpha + \cos^2\alpha - \sin^2\alpha = 2\cos^2\alpha + 2\sin\alpha\cos\alpha = 2\cos\alpha(\cos\alpha + \sin\alpha)$。

左边 $= \dfrac{2\cos\alpha(\cos\alpha + \sin\alpha)}{\cos\alpha + \sin\alpha} = 2\cos\alpha = $ 右边。

所以原等式成立。

2

已知 $\tan\theta = \dfrac{4}{3}$，且 $\cos\theta < 0$，求：

(1) $\sin 2\theta$；　(2) $\cos\left(\dfrac{\pi}{3} + \theta\right)$。

答案：(1) $\dfrac{24}{25}$；(2) $\dfrac{-3 + 4\sqrt{3}}{10}$
解析

由 $\tan\theta = \dfrac{4}{3} > 0$ 且 $\cos\theta < 0$，可知 $\theta$ 在第三象限。

$\sin\theta = -\dfrac{4}{5}$，$\cos\theta = -\dfrac{3}{5}$。

(1) $\sin 2\theta = 2\sin\theta\cos\theta = 2 \times \left(-\dfrac{4}{5}\right) \times \left(-\dfrac{3}{5}\right) = \dfrac{24}{25}$。

(2) $\cos\left(\dfrac{\pi}{3} + \theta\right) = \cos\dfrac{\pi}{3}\cos\theta - \sin\dfrac{\pi}{3}\sin\theta = \dfrac{1}{2} \times \left(-\dfrac{3}{5}\right) - \dfrac{\sqrt{3}}{2} \times \left(-\dfrac{4}{5}\right) = \dfrac{-3 + 4\sqrt{3}}{10}$。

讲评小结

6.1 正切和差角公式

  • 整体识别 $\tan(\alpha \pm \beta)$ 的结构
  • 巧用 $1 = \tan 45^\circ$ 进行变形
  • 注意公式中分子分母的符号

6.2 二倍角公式

  • 正用、逆用、变形用三种方向
  • $\cos 2\alpha$ 三种形式灵活选择
  • 半角问题常把 $\alpha$ 看成 $2 \times \dfrac{\alpha}{2}$

通用技巧

  • 先定象限，再定符号
  • 化简时先统一函数名称
  • 证明题从复杂边化向简单边
  • 遇到 $1$ 想平方和或特殊角

易错提醒

  • 开平方必须判断角所在象限
  • 正切公式注意定义域限制
  • 三角形中最大内角范围是 $\left(\dfrac{\pi}{3}, \pi\right)$
